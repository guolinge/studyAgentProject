# 作图规范(飞书兼容 SVG,single source of truth)

所有图以**自包含 SVG** 产出,插入飞书画板(`<whiteboard type="svg">`)。飞书画板的解析器不加载外部 CSS、不支持部分 SVG 特性,故必须严格遵守下面的硬约束,否则图会渲染成乱码/黑块。

## 硬约束(违反 = 渲染失败)

- **自包含**:所有样式**内联到元素属性**(`fill`/`stroke`/`stroke-width`/`font-size`/`font-weight` 等)。**禁止 `class=`、禁止 `<style>`、禁止外部 CSS/字体**。
- **必带 `viewBox`**:如 `<svg viewBox="0 0 640 470" xmlns="http://www.w3.org/2000/svg">`。
- **禁用元素**:`<pattern>`、`<mask>`、`<clipPath>`、`<foreignObject>`、以及非阴影 `<filter>`(只有 `feDropShadow` 允许,且最多一个)。
- **文字必须用 `<text>`**(不能靠 HTML);给足宽度:中文按每字约 1em、拉丁约 0.6em 估算,避免溢出卡片。
- **箭头**:用 `<polygon>` 手绘三角箭头;连线用**正交折线** `<polyline>` 或 `<line>`(水平/垂直),不用斜线。

## 审美规范(借鉴 archify/Cocoon,力求清爽专业)

- **画布**:浅色底(如 `#f8fafc`);整体留白充足,元素对齐。
- **配色板**(浅底 + 同色系描边 + 深色文字,协调不刺眼):
  - 琥珀:`fill #fef3c7 / stroke #d97706 / text #78350f`
  - 蓝:`fill #e0f2fe / stroke #0284c7 / text #0c4a6e`
  - 绿:`fill #dcfce7 / stroke #16a34a / text #14532d`
  - 紫:`fill #e0e7ff / stroke #4f46e5 / text #312e81`
  - 中性(连线/次要文字):`#64748b` / `#475569`
- **节点卡片**:圆角矩形 `rx="10~12"`,`stroke-width="2"`;可在左上角放一个小 `<circle>` 作色点提质感。
- **字号层次**:大标题 ~24、节点主标题 ~17 且 `font-weight="bold"`、副标题/标签 ~12,拉开层级。
- **边标签**:放在连线旁(中性色小字),说明关系(如"硬链接""调用""返回")。

## 图型选择

- 流程/决策:纵向或横向排布的卡片 + 正交箭头(分支用不同走向)。
- 架构/分层:分层卡片,层间箭头标注关系。
- 时序:参与者竖泳道 + 横向消息箭头(带 y 轴顺序)。
- 关系/数据流:节点 + 有向连线,必要时加图例。

## 产出

只产出**一个** `<svg>…</svg>`,不要多余解释。若收到校验诊断(如"使用了 class""缺 viewBox"),据此修正后重新产出完整 SVG。
