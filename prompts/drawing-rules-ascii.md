# 字符画图规范（ASCII，硬约束）

用纯文本字符画图，放进围栏代码块（等宽渲染）。只需遵守下面的硬约束——违反会导致渲染乱码或对齐崩坏。

## 字符集（分两类，严格区分）

- **结构/连线字符**：框线用 `+ - |`，箭头用 `> < ^ v`，斜线 `/ \` 少用。**只能用这些**画框和连线。
- **文字标签**：框内/线旁的文字可用中文、英文、数字、标准标点。中文/全角字符在等宽字体下按 **2 列宽**计算，参与列宽核算。

## 禁用字符（一律不准出现）

Unicode 制表符/装饰符会在等宽环境里错位或显示成方块，禁止使用：
`┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼ ╔ ╗ ╚ ╝ ═ ║ ╭ ╮ ╰ ╯ ▶ ▼ ◀ ▲ ● ○ ◆ ◇`

## 宽度

每行显示列宽 ≤ 100 列（中文按 2 列计），优先 ≤ 80。

## 画什么样的图(质量导向)

图的价值是给读者**文字不易传达的空间直觉**,所以要有复杂度和启发性:

- **展示关系,不装文字**:图要呈现"多个节点 + 它们的关系 + 流向/分层/时序",而不是把一句话框起来。孤立的单个方框没有信息量。
- **常见有信息量的图型**:分层架构(上下分层 + 跨层箭头)、数据流/请求路径(带方向的管线)、时序对比(两条时间轴并排看差异)、状态迁移(状态 + 触发条件)、树/层次结构。挑最能说明该处机制的一种。
- **在关键处加简短标注**:箭头旁标动作、节点旁标状态或数值,让图自解释。
- **对比型优先并排**:讲"A vs B""改进前后"时,把两者画成并排或上下两栏,差异一眼可见——这是最有启发性的图型之一。

## 产出

只输出图本身（放进围栏代码块）。中文标签要按 2 列宽把框宽算准，保证上下边框与内容行对齐。
